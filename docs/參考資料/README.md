## 二、檔案編碼與處理注意事項

1. **UTF-8 with BOM (`\ufeff`)**：
   - 官方 CSV 檔案預設帶有 UTF-8 位元組順序記號（BOM，Byte Order Mark，十六進位 `EF BB BF`）。
   - **讀取解析注意事項**：使用 Node.js `fs.readFileSync` 讀取並以文字解析時，若需逐欄比對首欄表頭（如 `代碼`），應注意移除前導 BOM 字元（例如 `content.replace(/^\ufeff/, "")`），避免比對首個欄位名稱時發生非預期不符。
   - **Excel 相容性**：保留 UTF-8 BOM 可確保 Windows 平台上的 Microsoft Excel 能直接以正體中文（CP950/UTF-8）正確開啟而不產生亂碼。

## 三、代碼架構與欄位規格

### 1. 課程代碼（23 碼）編碼結構

108 課綱技術型高級中等學校課程代碼由 23 碼固定字元組成：
- **第 1 碼（課程類型）**：`V`（技術型）、`H`（普通型）、`S`（綜合型）等。
- **第 2~4 碼（學校代碼）**：主管機關核定之教育部學校代碼後 3 碼。
- **第 5~7 碼（群科代碼）**：
  - `101`～`811`：標準技術型群科（例如 `301` 機械科、`501` 電機科、`502` 電子科、`504` 資訊科）。
  - `A01`～`Y02`：實用技能學程（例如 `A01` 機械技術學程、`G01` 微電腦修護學程）。
- **第 8 碼（開課年級）**：`1`（高一）、`2`（高二）、`3`（高三）。
- **第 9 碼（入學學年度）**：例如 `A` 代表 110 學年度入學、`B` 代表 111 學年度入學、`C` 代表 112 學年度入學等。
- **第 10 碼（開課屬性）**：`1`（部定必修）、`2`（校訂必修）、`3`（校訂選修）等。
- **第 11 碼（科目屬性）**：`1`（一般科目）、`2`（專業核心科目）、`3`（實習科目）等。
- **第 12~17 碼（科目固定編碼）**：對應 `科目固定編碼.csv` 中的唯一識別碼。
- **第 18~23 碼（流水號與分組碼）**：各校自訂開課流水號與分組設定。

### 2. 適用課程類型代碼對照表

在 `科別代碼.csv` 與 `科目固定編碼.csv` 之「適用課程類型」欄位中，各英文字母代表意義如下：
- `|H|`：普通型高級中等學校（高中）
- `|V|`：技術型高級中等學校（高職）
- `|S|`：綜合型高級中等學校（綜高）
- `|M|`：實用技能學程
- `|C|`：進修部 / 進修學校
- `|E|` / `|F|` / `|G|`：各專案學程與特殊專班

## 四、專案同構模組對應與 1NF 正規化邊界

本專案實作秉持「**技術型高中 39 欄全數展開為 14 欄 1NF 紀錄**」之核心演算法原則：

1. **不剔除任何科目原則**：
   - 本範本專案不作特定群科或科目的硬性過濾，無論一般科目、專業科目或彈性學習課程，一律按規範全數轉為正規化資料庫列。
2. **前後端模組對齊映射**：
   - [courseNormalizationShared.js](file:///home/cookeyholder/Projects/GAS-Course-Web-Template/courseNormalizationShared.js)：以緊湊格式載入 368 筆標準群科代碼與別名池，提供前後端同構之 `compareDepartmentsByCode` 排序演算法。
   - [subjectCodeTransformer.js](file:///home/cookeyholder/Projects/GAS-Course-Web-Template/subjectCodeTransformer.js)：後端試算表展開核心，將寬表展開為 14 欄標準紀錄。
   - [webapp/js/courseData.js](file:///home/cookeyholder/Projects/GAS-Course-Web-Template/webapp/js/courseData.js)：瀏覽器端即時展開預覽與統計引擎。
